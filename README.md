# VISION → TOUCH

**딥러닝 기반 이미지의 촉각 물성 예측을 통한 로봇 그리퍼 제어**를 주제로 한 한국어 인터랙티브 연구 보고서입니다. 정연준·강준혁·권준현의 2학기 활동 기록을 바탕으로 작성했습니다.

## 열기

`index.html`을 브라우저에서 열면 됩니다. 빌드, 패키지 설치, API 키가 필요하지 않습니다. HTML·CSS·JavaScript가 같은 폴더에 있어야 합니다.

## 기능

- 전체 뷰포트를 사용하는 마인드맵: 6개 카테고리, 중심 노드, 넓은 화면의 하위 노드
- 마우스·터치·펜이 같은 물리/조작 경로를 사용하며, 한 노드를 당기면 연결된 중심과 다른 가지에도 힘이 전달됨
- 마우스 왼쪽 버튼으로 노드 직접 드래그, 빈 배경 드래그로 전체 지도 이동, 로고를 눌러 지도 중앙으로 복귀
- 모션은 항상 기본 활성화. 모션 버튼과 지도 초기화 버튼, 조작 안내는 표시하지 않음. 네이티브 링크 드래그 차단, 포인터 캡처·창 밖 이동·포커스 상실 처리
- 제목을 제외한 캔버스 공간에 맞춘 배치. 창 크기·방향·브라우저 확대 변경에 대응하고 좁고 낮은 창에서는 간결한 배치 사용
- 자체 질량–스프링 엔진: 스크롤·터치 드래그 충격, 관성, 복원력, 감쇠, 노드 충돌과 경계 반응
- 스크롤을 내리면 노드가 위로, 올리면 아래로 움직이고 제자리로 복귀
- 노드 탭/클릭 → 전체 화면 보고서. X / Esc → 같은 마인드맵으로 복귀
- 클릭과 드래그 구분, 키보드 탐색, 목차, 주소 해시, 이전/다음 탐구
- 단계별 시스템 도식, 조절 가능한 EMA 비교 그래프, 서보 가감속 그래프
- 본문 도표의 빈 곳 드래그, 관성 이동, ± 확대·축소, 원위치 복귀와 키보드 조작
- 서보 그래프의 점과 그리퍼 직접 드래그, 물성 레이더 차트의 세 손잡이 직접 조절
- 슬라이더·프리셋에 따른 곡선과 차트의 부드러운 변화
- 물성 레이더 차트, 잡기 시 예측값 저장, 고정 위치로 닫히는 설명용 그리퍼
- 날짜별 세 사람의 활동 기록 비교, 구현/검증 범위 도식
- 전체 보고서와 PDF 인쇄, 모바일 대응
- 사용자 요청에 따라 기존 모션 설정과 관계없이 효과를 활성화하며, 로컬 저장소의 이전 꺼짐 설정은 사용하지 않음
- 버튼은 잡기, 열기, 이전, 다음, 인쇄처럼 짧은 이름을 사용하며 조작 안내 문구와 장식적인 구분자를 제거
- 런타임 외부 라이브러리·폰트·분석 도구·데이터 전송 없음

그래프의 신호, EMA 비율, 가감속 곡선과 물성 프리셋은 **설명용**입니다. 실제 측정 데이터나 원본 모델·제어 코드의 실행 결과가 아닙니다.

## 화면 전환과 모션 구현

`content.js`에 근거 기반 내용, `physics.js`에 물리 계산, `layout.js`에 화면 크기별 노드 배치, `interactions.js`에 도표의 공통 마우스·터치·펜 제스처와 보간, `report.js`에 화면·시각화를 분리했습니다. 브라우저의 네이티브 `dialog.showModal()` 대신 `hidden` 속성으로 지도와 본문을 전환합니다. 각 노드는 일반 해시 링크로 제공하고, SVG 연결선은 클릭을 가로채지 않습니다. HTML의 파일 버전 쿼리로 이전 JS/CSS 혼용을 줄였습니다.

지도는 2차원 벡터 스프링으로 가로·세로·접선 방향의 당김을 연결 그래프 전체에 전달합니다. 약한 기준점 복원력과 감쇠로 놓은 뒤에는 원래 배치로 돌아옵니다. 반암시적 오일러 적분과 작은 시간 간격으로 업데이트합니다. 프레임 시간과 속도를 제한하고, 화면이 숨겨지거나 본문을 열면 애니메이션을 멈춥니다. 실제 로봇의 운동을 시뮬레이션하는 엔진이 아니라 지도 UI의 상호작용을 위한 물리 모델입니다.

## 근거와 구현 범위

주요 출처: [2026_로봇소리 / 2학기활동내용](https://docs.google.com/spreadsheets/d/1lrLXjXqZK7DK3e-dUuap6zjmhxhJdHIiu68cVr3lSZ8/edit#gid=1549448282), 2026-11-11 확인.

| 작성자 | 범위 | 반영 내용 |
| --- | --- | --- |
| 정연준 | D5:H5 | 이미지 학습, 라이브러리 오류 해결, 웹캠 물성 예측, 스레드 분리, EMA, 버튼 입력과 모터 제어 |
| 강준혁 | D6:H6 | 초기 하드웨어 구상, 이미지 학습, 하드웨어 제작과 서보 동작 오류 해결. F6/G6의 미완성 문구는 추측해서 채우지 않음 |
| 권준현 | D8:H8 | 두 서보 그리퍼, 기존 학습 가중치, 224×224 전처리, 실험용 제어 규칙, 예측값 저장과 고정 각도 제어 구분 |

확인 가능한 결과는 **활동자가 기록한 구현 및 개선 과정**입니다. 예측 정확도, 힘(N), 파지 성공률, 재질별 반복 실험 결과는 제공되지 않았습니다. 각도·속도 제어를 실제 파지력 측정·폐루프 제어로 표현하지 않습니다. 0.4초는 설정한 추론 주기이며 실측 지연이 아닙니다. 정규화된 마찰 예측값은 실제 마찰계수가 아닙니다.

정연준의 물성 기반 목표 위치 조절 기록과 권준현의 고정 각도 제어 기록은 각각 표시했습니다. 통합 원본 코드 확인 전까지 하나의 검증된 최종 제어 알고리즘으로 합치지 않았습니다.

사용자가 제공한 ‘재질에 따른 파지력 조절’ 공유 채팅은 웹 접근 시간 초과 및 HTTP 503으로 본문을 읽지 못했습니다. 대화 원문·소스코드·가중치·학습 데이터·실험 사진/동영상은 아직 반영하지 않았습니다. 이 사이트의 도식과 체험은 설명용이며 실물 사진이나 실제 제어 코드가 아닙니다.

## 구성 선택

- Dreamhack 제공 화면: 노드 연결 구조는 카테고리의 관계를 한눈에 보여주는 데 유리합니다. 보고서 전문을 읽거나 작은 화면에서 탐색할 때는 단독 사용이 불편할 수 있습니다.
- [Nerfies](https://nerfies.github.io/): 연구 설명, 자료 링크와 인터랙티브 데모의 연결을 참고했습니다. 코드를 복사하지 않았습니다.
- 선택: **탐구 지도 + 전체 화면 읽기 + 목록 + 전체 보고서**. 관계 파악, 순서대로 읽기, 모바일 접근, 출처 확인을 함께 지원합니다. 이는 사용 목적을 기준으로 한 설계 판단이며 사용성 실험으로 입증한 우열은 아닙니다.

## GitHub Pages 게시

보고서 소스는 `dusloop/vision-torch-report`의 `main` 브랜치에 업로드했습니다.

1. 레포지토리 **Settings → Pages → Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
2. 브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 **Save**를 누릅니다.
3. 배포 후 Settings → Pages에 표시되는 주소로 접속합니다.

정적 사이트이므로 별도의 빌드 워크플로가 필요 없습니다. 공개 사이트: https://dusloop.github.io/vision-torch-report/

## 검증

사이트 자체는 빌드가 필요 없습니다. 테스트 도구만 설치하려면 `npm install` 후 `npm test`, `npm run check`를 실행합니다.

통과한 검사:

- JavaScript 문법, HTML 중복 ID, 로컬 자산 경로와 CSS 기본 검사
- DOM 이벤트 검사: 모든 노드 열기, X / Esc / 포커스 복귀, 다음·이전, 직접 링크, 클릭과 드래그 구분
- EMA 슬라이더, 궤적 끝점, 물성 저장값 유지·초기화, 타임라인, 전체 보고서
- 스크롤 반응, 로고 복귀, 기본 활성 모션 및 이전 꺼짐 설정 무시
- 데스크톱 포인터 캡처, 네이티브 드래그 차단, 1:1 노드 이동, 지도 이동, 창 포커스 상실, 구형 마우스 이벤트 경로, 드래그 직후 클릭, 리사이즈 도중 드래그 정리
- 14개 캔버스 크기에서 노드 잘림·겹침 없음, 최소 44px 클릭 영역, 6개 카테고리 유지
- 320×360부터 3840×2160까지 11개 viewport 입력의 DOM 검사
- 마우스·터치·펜 입력을 각각 실행해 연결 노드 이동 결과의 일치, 도표 관성·확대·초기화, 직접 그래프/그리퍼/레이더 조절, 저장값 유지, 확대된 SVG 좌표, 키보드와 화면 전환 중 정리 확인
- 접선 방향 당김의 두 단계 연결 전파와 전체 그래프 복원
- 물리 단위 검사: 질량 반응, 양방향 충격, 감쇠 복귀, 충돌, 극단 입력 시 유한값과 화면 경계, 드래그 해제

DOM 검사는 jsdom에서 실행하며, 모바일·태블릿·가로 화면의 viewport 입력도 검사합니다. 실제 CSS 배치·그리기·Safari 터치 동작을 검증하는 브라우저 테스트는 아닙니다. 이 환경에는 공유 브라우저 제어 도구가 없어 실제 렌더링 검증은 미완료입니다.
